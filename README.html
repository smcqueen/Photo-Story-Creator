Photo Story Creator 1.8

Offline thumbnail-based slideshow and timelapse authoring for Linux and Windows.

Start

  1. Extract the complete folder.
  2. Open index.html in a current Chromium or Firefox browser.
  3. Import photos and arrange the storyboard.
  4. Assign motion automatically, per image, or to a selected group.
  5. Apply optional crop, straighten, rotate, or flip transforms.
  6. Preview the story, check the workload estimate, and generate the renderer.

Efficient motion

Subtle zoom-in and zoom-out effects use a 2× output-size working canvas for smooth movement without processing full camera-resolution photographs. Pan and static slides stay on the faster final-resolution path. Linux renders fingerprinted completed clips so an interrupted render can resume without rebuilding unchanged clips. The default veryfast preset is recommended.

Relinking

Choosing a new image folder updates both storyboard thumbnails and the FFmpeg image-folder path. Nested relative paths are retained beneath the selected folder.

Transforms

The Transforms page provides a large live 16:9 preview for crop, straighten, rotate, and flip adjustments. Rotate commands accumulate in 90° steps; opposite rotations cancel, and each flip command toggles its axis on or off. Navigate among selected images, compare Before and After, zoom the workspace, and explicitly apply settings to the current image or all selected images. Settings are stored non-destructively in the project.

Export JPEG or Export PNG creates a transformed copy at the selected project output resolution. Export never overwrites the source photograph.

Preview

Browser preview includes motion, transforms, captions, transitions, title cards, seeking, audio, draft quality, and full-screen presentation.

Timing

Display duration is the full, uninterrupted hold assigned to each image. Fade, dissolve, wipe, and slide transitions add their configured time between image holds. Cut adds no visible time. Preview, duration estimates, generated renderers, and target-runtime fitting use the same timing model.

Renderer attention alerts

If the saved soundtrack path cannot be found after rendering the silent video, the Linux renderer sounds the terminal bell and uses a desktop notification when available before opening its file chooser. The Windows renderer sounds a system beep before opening its file chooser.

Soundtrack looping

When a soundtrack is shorter than the story, repetitions can overlap with a configurable 1, 2, 3, or 5 second crossfade; the default is 2 seconds. The renderer automatically shortens the overlap for unusually brief audio, trims the combined soundtrack to the exact story duration, and applies the selected opening and closing fades.

HEIC / HEIF

Use the included conversion tools to create JPEG working copies without modifying originals.
