Photo Story Creator 1.7.1

Offline thumbnail-based slideshow and timelapse authoring for Linux and Windows.

Start

  1. Extract the complete folder.
  2. Open index.html in a current Chromium or Firefox browser.
  3. Import photos and arrange the storyboard.
  4. Assign motion automatically, per image, or to a selected group.
  5. Apply optional crop, straighten, rotate, or flip transforms.
  6. Preview the story, check the workload estimate, and generate the renderer.

Efficient motion

Subtle zoom-in and zoom-out effects use a 2× output-size working canvas for smooth movement without processing full camera-resolution photographs. Pan and static slides stay on the faster final-resolution path. Linux renders fingerprinted completed clips so an interrupted render can resume without rebuilding unchanged clips. The default veryfast preset is recommended.

Relinking

Choosing a new image folder updates both storyboard thumbnails and the FFmpeg image-folder path. Nested relative paths are retained beneath the selected folder.

Transforms

Crop, straighten, rotate, and flip settings are stored in the project. Source photographs are never modified.

Preview

Browser preview includes motion, transforms, captions, transitions, title cards, seeking, audio, draft quality, and full-screen presentation.

HEIC / HEIF

Use the included conversion tools to create JPEG working copies without modifying originals.

Tests

Run python3 tests/run_tests.py.
