Photo Story Creator 1.3

Offline thumbnail-based slideshow and timelapse authoring for Linux and Windows.

Start

  1. Extract the complete folder.
  2. Open index.html in a current Chromium or Firefox browser.
  3. Import a folder, arrange the thumbnails, set timing and presentation options, then generate a render script.
  4. Run the generated script on a computer with FFmpeg installed.

Projects use the .pscproj format. Image files are not embedded in project files.

Version 1.3 fix

Cut transitions are now represented by exactly one video frame in the FFmpeg transition graph. This prevents mixed Cut and slide/fade sequences from collapsing to the duration of the first image.

Tests

Run python3 tests/run_tests.py. The FFmpeg regression test runs automatically when both FFmpeg and FFprobe are installed.
