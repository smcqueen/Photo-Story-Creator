Photo Story Creator 1.6

Offline thumbnail-based slideshow and timelapse authoring for Linux and Windows.

Start

  1. Extract the complete folder.
  2. Open index.html in a current Chromium or Firefox browser.
  3. Import individual photos, a complete folder, or drag image files onto the storyboard.
  4. Use Full-Screen Storyboard for large stories.
  5. Open Preview to review timing, transitions, captions, title cards, and audio.
  6. Generate the Linux or Windows FFmpeg renderer.

Preview and Playback

The responsive browser preview includes play, pause, restart, previous, next, timeline seeking, start-from-selected, elapsed time, image count, draft quality, and full-screen presentation. A soundtrack chosen in the current session plays with the preview; after reopening the browser, choose it again because browsers do not retain local file access.

Full-Screen Storyboard

The expanded workspace provides adjustable thumbnail sizing, filename/title/caption search, status filters, image-number navigation, long-distance group moves, cut/paste arranging, and a hideable inspector.

Captions

Select a photo to add a slide title, caption, or both. Text is stored in the project and burned into the rendered video through UTF-8 text files.

HEIC / HEIF

Convert HEIC files with tools/convert_heic_linux.sh or tools/convert_heic_windows.ps1. The tools create JPEG working copies without modifying originals.

Projects include compact thumbnail previews, not full-resolution media. Use Relink Images after moving source images.

Tests

Run python3 tests/run_tests.py.
