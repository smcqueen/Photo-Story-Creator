Photo Story Creator 1.5.2

Offline thumbnail-based slideshow and timelapse authoring for Linux and Windows.

Start

  1. Extract the complete folder.
  2. Open index.html in a current Chromium or Firefox browser.
  3. Import individual photos, a complete folder, or drag image files onto the storyboard.
  4. Use Full-Screen Storyboard for large stories.
  5. Add optional slide titles and captions, then generate the Linux or Windows FFmpeg renderer.

Full-Screen Storyboard

The expanded workspace provides adjustable thumbnail sizing, filename/title/caption search, status filters, image-number navigation, long-distance group moves, cut/paste arranging, and a hideable inspector. Press Escape or Return to editor to leave it without losing selection or project changes.

Captions

Select a photo to add a slide title, caption, or both. Choose the project-wide typography and position or override the position per slide. Text is stored in the project and burned into the rendered video through UTF-8 text files.

HEIC / HEIF

Convert HEIC files with tools/convert_heic_linux.sh or tools/convert_heic_windows.ps1. The tools create JPEG working copies in PSC_Converted without modifying originals. On Linux Mint or Ubuntu, install libheif-examples.

Audio files

Browsers hide a chosen audio file’s absolute folder for security. If the renderer cannot find the stored filename, it asks you to select the soundtrack before FFmpeg starts.

Projects use the .pscproj format and include compact thumbnail previews, not full-resolution media. Use Relink Images after moving source images.

Tests

Run python3 tests/run_tests.py.
