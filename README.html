Photo Story Creator 1.4.6

Offline thumbnail-based slideshow and timelapse authoring for Linux and Windows.

Start

  1. Extract the complete folder.
  2. Open index.html in a current Chromium or Firefox browser.
  3. Import individual photos, a complete folder, or drag image files onto the storyboard.
  4. Multi-select and drag thumbnails into order, then use the timing and audio controls.
  5. Generate the Linux or Windows FFmpeg renderer.

HEIC / HEIF

Desktop browsers generally cannot display HEIC thumbnails. Convert them first with tools/convert_heic_linux.sh or tools/convert_heic_windows.ps1. The tools create high-quality JPEG working copies in PSC_Converted and never modify the originals. Import that output folder into the storyboard.

On Linux Mint or Ubuntu, install the preferred converter with sudo apt install libheif-examples. The script can also use ImageMagick or an HEIC-capable FFmpeg. Keep PSC_Converted inside the original image folder; the renderer finds converted working copies there automatically. On Windows, install ImageMagick with HEIC support or an HEIC-capable FFmpeg and place it in PATH.

Audio files

Browsers hide a chosen audio file’s absolute folder for security. You may enter a full path in the Audio panel. If only a filename is saved and the renderer cannot find it, the renderer opens a file chooser before FFmpeg starts.

Projects use the .pscproj format. Compact thumbnail previews are embedded so the storyboard remains visual after reopening; full-resolution image and audio bytes are not embedded. Use Relink Images for older projects or after moving a source folder.

Tests
