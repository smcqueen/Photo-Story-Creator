Photo Story Creator 1.4.6

Version 1.4.6

  • Saved projects now contain compact thumbnail previews, so reopening a project restores the visual storyboard immediately.
  • Added a Relink Images action for older projects and source folders that have been moved.
  • Relinking preserves storyboard order, timing, transitions, captions, and HEIC conversion associations.

Version 1.4.5

  • Explains the browser restriction that hides the selected audio file's absolute folder.
  • Linux and Windows renderers now open an audio-file chooser when the saved basename cannot be found.
  • Both renderers validate the selected audio path before starting FFmpeg.

Version 1.4.4

  • Pairs HEIC/HEIF originals and converted JPEG working copies before adding either item to the storyboard.
  • Importing a parent folder that contains PSC_Converted now creates one storyboard item per HEIC photo, not a converted image plus a placeholder.
  • Re-importing PSC_Converted replaces pending placeholders when needed and otherwise skips photos already present.
  • Preserves storyboard position and timing when a converted JPEG replaces a placeholder.
  • Includes the v1.4.3 folder import, storyboard-order rendering, converted-image resolution, and stale-clip fixes.

Version 1.4.1

  • Added HEIC and HEIF recognition, conversion tools, placeholders, and matching JPEG replacement.

Version 1.4

  • Added individual and drag-and-drop photo import.
  • Improved multi-selection, group reordering, batch timing, timing locks, and audio workflow.
  • Preserved the frame-safe Cut and mixed-transition rendering fixes from v1.3.

Version 1.3

  • Fixed mixed Cut and animated transitions producing a video only as long as the first image.
  • Changed simulated Cut transitions to exactly one frame at the selected frame rate.
