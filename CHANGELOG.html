Photo Story Creator 1.8

Version 1.8

  • Added a large live 16:9 preview to the Transforms page.
  • Crop, straighten, rotate, and flip controls now update the preview immediately without changing the project until Apply is clicked.
  • Rotate Left and Rotate Right now accumulate in 90° steps and cancel one another; horizontal and vertical flip commands are reversible toggles.
  • Added Before/After comparison, preview zoom, and Previous/Next navigation through selected images.
  • Added explicit Apply to current image and Apply to all selected actions, plus matching reset actions.
  • Added transformed-copy export to JPEG or PNG at the project output resolution without overwriting source photographs.
  • Preserved the v1.7.2 full-hold timing, motion, soundtrack crossfade, and resumable-render behavior.

Version 1.7.2

  • Changed timing so every image retains its full requested display hold.
  • Animated transitions now add their configured time between image holds; Cut adds no visible time.
  • Updated runtime estimates, target-runtime fitting, browser preview, Linux and Windows renderers, and regression tests to use the same timing model.
  • Added audible and visible attention alerts before a long render pauses to request a missing soundtrack location.
  • Corrected Automatic Subtle Motion for a partial selection so it cycles through Zoom In, Pan Right, Zoom Out, and Pan Left regardless of where the selection begins in the storyboard.
  • Added configurable seamless soundtrack-loop crossfading on Linux and Windows, with a two-second default and automatic shortening for brief audio files.
  • Replaced internal storyboard state codes with readable transition and motion labels.
  • Changed automatic-motion controls to neutral action buttons and added explicit confirmation after selected-image or whole-story assignment.

Version 1.7.1

  • Fixed Relink Images so the selected folder becomes the FFmpeg image folder and nested relative paths remain valid.
  • Smoothed subtle zoom rendering with a 2× output-size working canvas while keeping pans and static slides on the faster final-resolution path.
  • Added a visible motion-and-strength indicator to the browser preview.
  • Added regression tests for relinking metadata, zoom canvas size, frame progression, and the zoom performance gate.

Version 1.7

  • Added automatic, per-image, and selected-group subtle zoom and horizontal pan motion.
  • Added non-destructive crop, straighten, rotate, and flip transforms.
  • Added motion preview, a workload estimate, output-scale animation, and resumable fingerprinted clip rendering.
  • Preserved compatibility with saved v1.2 through v1.6 projects.

Version 1.6

  • Added responsive in-browser preview and playback with play, pause, restart, previous, next, timeline seeking, and start-from-selected.
  • Preview includes project timing, transition animations, title cards, titles, captions, elapsed time, slide count, soundtrack playback, draft quality, and full-screen presentation.
  • Preserved compatibility with saved v1.2 through v1.5.2 projects.

Version 1.5.2

  • Fixed full-screen Jump so it scrolls the storyboard workspace directly, selects and highlights the destination, and works when a search or filter had hidden the requested image.
  • Added image-number validation and Enter-key activation.

Version 1.5.1

  • Added a dedicated full-screen storyboard for large photo stories.
  • Added adjustable thumbnail sizing, search, and filters for captioned, locked, HEIC, and missing images.
  • Added jump-to-number, move before/after number, move to beginning/end, and cut/paste group arranging.
  • Added a hideable inspector and preserved the live selection and project state when returning to the editor.

Version 1.5

  • Added separate slide-title and caption fields.
  • Added project typography controls for font family, text size, color, weight, shadow, background box, and safe margin.
  • Added top, center, and bottom positioning with per-slide overrides.
  • Added live title and caption previews on storyboard thumbnails and in the inspector.
  • Burns UTF-8 titles and captions into Linux and Windows FFmpeg output while preserving compatibility with older projects.

Version 1.4.6

  • Saved projects now contain compact thumbnail previews, so reopening a project restores the visual storyboard immediately.
  • Added a Relink Images action for older projects and source folders that have been moved.
  • Relinking preserves storyboard order, timing, transitions, captions, and HEIC conversion associations.

Version 1.4.5

  • Explains the browser restriction that hides the selected audio file's absolute folder.
  • Linux and Windows renderers now open an audio-file chooser when the saved basename cannot be found.
  • Both renderers validate the selected audio path before starting FFmpeg.

Version 1.4.4

  • Pairs HEIC/HEIF originals and converted JPEG working copies before adding either item to the storyboard.
  • Importing a parent folder that contains PSC_Converted now creates one storyboard item per HEIC photo, not a converted image plus a placeholder.
  • Re-importing PSC_Converted replaces pending placeholders when needed and otherwise skips photos already present.
  • Preserves storyboard position and timing when a converted JPEG replaces a placeholder.
  • Includes the v1.4.3 folder import, storyboard-order rendering, converted-image resolution, and stale-clip fixes.

Version 1.4.1

  • Added HEIC and HEIF recognition, conversion tools, placeholders, and matching JPEG replacement.

Version 1.4

  • Added individual and drag-and-drop photo import.
  • Improved multi-selection, group reordering, batch timing, timing locks, and audio workflow.
  • Preserved the frame-safe Cut and mixed-transition rendering fixes from v1.3.

Version 1.3

  • Fixed mixed Cut and animated transitions producing a video only as long as the first image.
  • Changed simulated Cut transitions to exactly one frame at the selected frame rate.
