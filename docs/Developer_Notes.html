Developer Notes

The browser remains fully offline. Full-resolution images use temporary object URLs; bounded JPEG previews are stored in projects.

Version 1.7.1 resolves automatic motion deterministically and applies transforms before motion processing. Zooms use a 2× output-size working canvas to reduce integer stepping, then emit the selected resolution and frame rate. Pans and static slides remain at final resolution. Linux render clips use project-setting fingerprints so unchanged completed clips survive interrupted runs.

Relinking records the selected directory as imageFolder and stores each matched image path relative to that root.

The preview derives a read-only, overlap-aware timeline from live project state and uses browser animations to approximate FFmpeg motion and transitions.

Older projects receive safe defaults. Source image bytes are never modified by transforms.
