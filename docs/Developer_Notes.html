Developer Notes

The browser remains fully offline. Full-resolution images use temporary object URLs; bounded JPEG previews are stored in projects.

Version 1.7.2 preserves the full logical hold for every image and treats animated transitions as additive intervals. FFmpeg still uses xfade; generated clip durations include the incoming visible transition and the following transition's technical tail so the composed duration equals holds plus visible transitions. Frame-safe simulated Cuts remain zero-duration in the user timing model.

Automatic motion is deterministic and transforms are applied before motion processing. Zooms use a 2× output-size working canvas to reduce integer stepping, then emit the selected resolution and frame rate. Pans and static slides remain at final resolution. Linux render clips use project-setting fingerprints so unchanged completed clips survive interrupted runs.

File soundtracks are repeated through a dynamically generated acrossfade graph. Repetition count accounts for overlap, crossfade length is capped at half the source duration, and the combined audio is trimmed to the exact story runtime before its final fade.

Relinking records the selected directory as imageFolder and stores each matched image path relative to that root.

The preview derives a read-only additive timeline from live project state and uses browser animations to approximate FFmpeg motion and transitions.

Older projects receive safe defaults. Source image bytes are never modified by transforms.
