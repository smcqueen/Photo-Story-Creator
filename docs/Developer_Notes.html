Developer Notes

The browser remains fully offline. Local full-resolution images use temporary object URLs for the active session; bounded 320-pixel JPEG previews are stored in saved projects. Render scripts normalize each item to a clip and regenerate clips in current storyboard order. Transitions use FFmpeg xfade. Caption and title text is written to UTF-8 text files and consumed with drawtext textfile mode.

The v1.6 preview derives a separate read-only playback sequence and overlap-aware timeline from live project state. It uses thumbnail sources in draft mode, full session sources otherwise, browser animations for transition review, requestAnimationFrame for timing, the Fullscreen API for presentation, and an in-session Audio object for soundtrack playback.

The full-screen workspace moves the live storyboard DOM between containers rather than duplicating state. Selection, order, timing, captions, undo history, and drag behavior therefore remain identical in both views.

Relink Images reconnects saved entries to source files without changing their order or editing metadata.
