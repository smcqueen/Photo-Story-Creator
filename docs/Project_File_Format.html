.pscproj format — version 1.6

UTF-8 JSON. Stores the ordered image list, individual durations, timing locks, slide titles, captions, per-slide caption positions, typography settings, transitions, motion metadata, title-card settings, output settings, audio settings, and project metadata. It stores compact JPEG thumbnail previews but intentionally excludes full-resolution image bytes, audio bytes, and browser object URLs.

Preview position, playback state, full-screen storyboard search, filters, thumbnail size, and cut buffer are workspace UI state and are not added to project data.

Version 1.6 remains compatible with version 1.2 through 1.5.2 project data; missing fields receive safe defaults.
