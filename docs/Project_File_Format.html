.pscproj format — version 1.9.1

UTF-8 JSON. Stores ordered images, timing, captions, transitions, per-image motion, non-destructive crop/straighten/rotate/flip transforms, title cards, output, audio, and project metadata. Compact thumbnail previews are included; full-resolution image and audio bytes are excluded.

Version 1.9.1 opens version 1.2 through 1.8 projects. Editing history is session-only and is not written to the project. IndexedDB recovery records wrap an ordinary project snapshot with recovery metadata and remain separate from downloaded .pscproj files. No destructive source-image data or external-editor metadata is added. Stored image durations remain full display holds; animated transition durations are additional. Missing motion and transform fields receive safe defaults.
