.pscproj format — version 1.8

UTF-8 JSON. Stores ordered images, timing, captions, transitions, per-image motion, non-destructive crop/straighten/rotate/flip transforms, title cards, output, audio, and project metadata. Compact thumbnail previews are included; full-resolution image and audio bytes are excluded.

Version 1.8 opens version 1.2 through 1.7.2 projects. Its transform preview and JPEG/PNG export reuse the existing per-image transform object; no destructive source-image data or external-editor metadata is added. Stored image durations remain full display holds; animated transition durations are additional. Missing motion and transform fields receive safe defaults.
