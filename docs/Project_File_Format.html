.pscproj format — version 1.4.6

UTF-8 JSON. Stores the ordered image list, individual durations, timing locks, captions, transitions, motion metadata, title-card settings, output settings, audio settings, and project metadata. It stores compact JPEG thumbnail previews but intentionally does not contain full-resolution image bytes, audio bytes, or browser object URLs.

HEIC placeholders use heicPending until a matching filename.heic.jpg working copy is imported. The converted filename is then stored while originalName and convertedFrom preserve provenance.

Version 1.4.6 remains compatible with version 1.2, 1.3, and 1.4 project data. Older projects can restore previews with Relink Images.
