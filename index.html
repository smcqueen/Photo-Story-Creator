Help
Important workflow notes
  • Undo and Redo retain up to 100 meaningful project edits in the current session. Selection, scrolling, search, filtering, and preview zoom are not recorded.
  • A recovery copy protects unsaved work in this browser. It is not a project file; use Save Project to download a durable .pscproj file.
  • The save-state indicator distinguishes Never saved, Unsaved changes, Recovery copy saved, Saved, and Recovery failed. If recovery fails, save the project manually before leaving.
  • Thumbnails are generated locally and are never uploaded.
  • Saved projects include small thumbnail previews, not full-resolution image bytes. Use Relink Images when opening an older project or after moving its source folder.
  • Captions are rendered through temporary UTF-8 text files to reduce FFmpeg escaping problems.
  • Use the same image folder path in the project and on the computer that runs the generated script.
  • Display duration is the full hold for each image. Animated transition time is added between holds; Cut adds no visible time.
